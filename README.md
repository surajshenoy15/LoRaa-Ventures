# LoRaa Ventures Website

Professional React + Vite website for LoRaa Ventures, featuring LoRaa Connect and a Play Store-ready privacy policy page.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Routes

- `/` — LoRaa Ventures home page
- `/privacy-policy` — LoRaa Connect privacy policy

## Logo usage

- `public/loraa-logo-blue.svg` is used on white and light backgrounds.
- `public/loraa-logo-white.svg` is used on dark blue backgrounds.

The included SVG assets are clean web variants based on the supplied logo preview. You may replace them with the original transparent PNG exports while keeping the same filenames.
